# Grial · Centro de operaciones

Esta carpeta es la "oficina" de la agencia. Aquí viven las plantillas, los documentos comerciales y un folder por cada cliente.

**Para retomar o hacer la web de la agencia, lee primero [RESUMEN.md](RESUMEN.md):** lo hecho hasta ahora, las rutas, los enlaces y los pasos.

## Por dónde empezar (viernes 13 de noviembre)
1. Lee el plan: [docs/Plan_de_Trabajo_Agencia.pdf](docs/Plan_de_Trabajo_Agencia.pdf)
2. Revisa los nombres candidatos: [agencia/marca/nombres.md](agencia/marca/nombres.md)
3. Revisa y ajusta los documentos comerciales en [comercial/](comercial/)
4. Abre Claude Code en esta carpeta y pide la tarea del día (ver ejemplos abajo)

## Mapa de carpetas
| Carpeta | Para qué sirve |
|---|---|
| `comercial/` | Precios, propuesta, contrato, formulario de onboarding, guiones de venta |
| `clientes/` | Un folder por cliente. `_plantilla-cliente` es el molde que se copia |
| `plantillas/` | Web base, app base, automatizaciones y kit de publicación (se construyen en las semanas 1–3) |
| `agencia/` | Marca, web y app demo de la propia agencia |
| `operaciones/` | CRM de prospectos (CSV, se abre en Excel o Google Sheets) y tablero de proyectos |
| `docs/` | Plan de trabajo |

## Cómo pedirle trabajo a Claude (ejemplos)
- "Nuevo cliente: Clínica Sonrisa. Crea su carpeta y completa el brief con estos datos: …"
- "Construye la web de la agencia según el plan de la semana 1."
- "Prepara la propuesta para [cliente] con el paquete Crecimiento."
- "Actualiza el tablero de proyectos."
